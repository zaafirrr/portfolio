# Company logos

Save each logo in this folder using **exactly** the file name below.
The site picks it up automatically and shows it instead of the letters.
PNG, SVG, JPG and WEBP all work; a square image with a transparent or
white background looks best.

logo → Save image as) or their official press / brand page.

If a file is missing or misnamed, the letters simply stay.
